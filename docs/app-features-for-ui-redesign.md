# NanoKVM Pro Android — 现有功能全景(界面再设计输入)

> **本文用途**:交给另一个 AI 做 UI/UX 优化设计时的完整功能事实清单。只描述"现在有什么、怎么工作",不限定新方案。
> **配套材料**:设计基调见 `.workbench/spec.md`(finesse-brief 产出,含视觉令牌与自检三问);本文 §6 摘录其要点。
> **版本基准**:v0.1.3(2026-09-06)。功能以代码为准,与 `HANDOFF.md` 交叉校对过。

---

## 1. 产品是什么

一句话:**在 Android 手机/平板上,远程看到并操控一台电脑的桌面**(被控端 = Sipeed NanoKVM-Pro 硬件,AX630C,固件 v1.2.15,App 纯前端不改服务器)。

- **使用者**:一个人(设备主人),单设备、单会话;典型场景是"人不在电脑前,但要盯着屏幕、敲命令、派 AI 干活"。
- **每次打开的心智**:看状态(连上没/有画面没) → 介入(键鼠/终端) → 用完即走。
- **连接目标**:局域网 `https://<host>`(自签证书),设备默认 admin/admin;HDMI 输出典型 3840×2160@30fps。

## 2. 信息架构

```
AppNav(导航栈)
├─ Connect 连接页(startDestination)
└─ Console 主控台(核心页,全 App 的 home)
   ├─ SettingsSheet 设置底部抽屉(视频流/鼠标模式)
   ├─ ConsoleToolsSheet 工具箱抽屉(操作 | 设备管理 双页)
   │  └─ 15 个功能弹窗(见 §3.4)
   ├─ VirtualKeyboard 虚拟键盘(底部条)
   └─ StatsOverlay 性能统计浮层(视频右上)
├─ Terminal 终端页(Shell / 串口 / 助手安装 三种入口)
└─ Assistant 智能助手对话页
```

导航关系:connect →(连接成功)→ console →(工具箱/顶栏)→ terminal / assistant;返回一律 popBackStack。终端/助手从 console 带参进入,退出回 console。

### 3.2 Console 主控台

**顶栏(状态行)**
- 三个状态 chip(圆点色 + 标签 + 值,28dp 高,可扫读):
  - **画面**:值 = `3840×2160`(绿)/ `等待首帧…`(黄)/ `无画面`(红)/ `连接中…`(黄)
  - **会话**:正常 = `H.264 · 直连` 等编码·传输组合;异常 = `重连中 N` / `连接中…` / `错误`(tone 随之变化)
  - **鼠标**:`绝对` / `相对`
- 右侧:日/夜主题切换、⋮ 菜单(断开连接[红]/ 返回)

**ActionBar(图标工具条,图标 20dp + 40dp 命中区 + 11sp 文字标签)**
设置(开设置 Sheet)/ 鼠标(一键切换绝对↔相对)/ 键盘(开/关虚拟键盘)/ 工具箱(开抽屉)……右侧组:性能(开/关统计浮层)/ 重连(手动重建会话)。

**视频区(页面主体)**
- 满屏点阵底纹 letterbox,视频等比居中于黑色矩形,中心十字光标(黑外白内细线)。
- **触控鼠标手势**(视频矩形上):
  - 绝对模式:点按=左键单击;快速双击=右键;长按 ~600ms 后拖动=左键拖拽;双指竖滑=滚轮(方向可反向)。
  - 相对模式:拖动把位移折算成 ±127 的相对报告发给远端(光标位置不映射)。
- **本地变换(仅直连)**:旋转 0/90/180/270、缩放 50–200%(手势坐标做了逆映射,旋转缩放下点哪仍是哪)。WebRTC 模式变换禁用(渲染层限制,UI 上给原因文案)。
- **覆盖层三态**:
  - 连接中:半透明黑 + spinner + 阶段文案(登录中/配置流/建连中…)+ "第 N 次重连…"
  - 连接失败:整页底色 + "连接失败" + 具体错误 + "重连"按钮(≤260dp)
  - 无信号:图标 + "无信号 · 被控机可能已关闭显示器输出" + "刷新"

**性能统计浮层(右上 276dp 半透明黑卡)**
- 顶部:编码·传输 chip + 分辨率 chip + 关闭。
- 指标瓦片网格(按传输自适应,数值等宽字体,超阈值红字):
  - 直连:码率 / 实时帧率 / 解码延迟 / 抖动缓冲 / 总测延迟
  - WebRTC:码率 / 实时帧率 / 抖动缓冲 / ICE RTT / 丢包 / 总测延迟
- 三条 34dp 曲线(实时帧率 / 码率 / 总测延迟),40 点窗口,uPlot 蓝 #3B82F6 + 渐变填充 + 右缘实时端点。
- 总测延迟 > 250ms 或丢包 > 0 → 数值红。

**设置 Sheet(底部)**
- "视频流"两组分段按钮:H.264 | H.265;直连 | WebRTC(组合成固件模式串)。
- "鼠标模式":绝对 | 相对。
- "应用并重连"主按钮(切流必须重建会话);选择即持久化。

**虚拟键盘(底部条,等宽键块)**
- F1–F12 横滚行;修饰行 Ctrl/Alt/Shift/Win/⇥/Esc(修饰键=粘滞开关,点一次按住、再点释放);数字行;三行 QWERTY;底部 ←↑↓→ / ⌫ / 空格 / ⏎ / CLR。
- 按键直发 HID 报告(与物理键盘共用一条状态流)。

### 3.4 工具箱各弹窗(15 个)

1. **确认对话框**(通用):标题"确认操作"+ 说明 + 执行/取消;所有破坏性动作必经。
2. **设备信息**:IP(多网卡列表)/ mDNS / 固件版本 / 镜像 / 架构 / 设备号 / 型号 / 账户;键值行,值等宽字体。
3. **粘贴文本**:多行输入 ≤1024 字,含非 ASCII 实时警示(仅支持标准键盘字符);按钮"粘贴到远程主机"(走设备 HID paste 接口)。
4. **EDID 显示器参数**:6 个预设(4K30 / 4K39 / 2K60 / 1080P60 / 4K16:10 / 3440×1440 带鱼屏)+ 自定义列表;当前项高亮"使用中";支持上传自定义 .bin、删除自定义项;脚注提示切换后需重新协商分辨率。
5. **镜像**:硬盘 | CD-ROM 分段 + 只读开关;上传 .img/.iso(自动 8MB 分片,进度"x/y 块");文件列表点按挂载/再点卸载(已挂载高亮"已挂载·点按卸载");SHA256 在线校验(固件不支持时降级提示);删除;底部当前挂载状态行。
6. **脚本**:设备脚本目录列表;每项"运行"(前台,弹黑底等宽日志窗)/"后台";空态说明 web 端可上传。
7. **Wake-on-LAN**:MAC 输入 + "唤醒";历史列表(可改名/单独唤醒/删除);空态"唤醒成功后自动保存"。
8. **串口终端配置**:串口(ttyS1/ttyS2 快捷 chips)/ 波特率 / 校验位(无偶奇)/ 流控(无软硬)/ 数据位(5–8)/ 停止位(1–2)→"连接串口"进终端页。
9. **智能助手入口**:功能说明 + "会真实操控被控电脑"红色警示;"安装依赖"(跳终端页看 pip 进度)/"启动并进入对话"(进助手页);提示模型 Key 在对话页设置。
10. **设备监控**:副标题行(间隔 · 已采次数 · 窗口分钟);6 张数字卡(CPU / 内存 / 温度 / 负载(1m) / 内存占用 / 采样间隔);采样间隔 1/2/5/10s 分段(切换 toast);三条滚动曲线(CPU 紫 / 内存绿 / 温度橙,75 点固定窗口,渐变+端点);数据来源脚注(/proc/stat 等)。
11. **设备设置**:主机名(保存,重启生效)/ SSH 开关 / mDNS 开关 / HDMI 采集开关 / HDMI 直通开关 / 静态 IP(开关 + IP 输入 + 应用,失联红色警示)/ Wi-Fi(状态、扫描列表含信号强弱、当前网络高亮"已连接/重连"、点选输密码连接、断开;AP 模式有提示)。旧固件缺端点的项逐项降级"固件不支持",不影响其他项。
12. **显示·时间·账户**:OLED 息屏秒数 / LCD 时间格式 12h|24h / LCD 定时熄屏(开关 + 起止 HH:mm)/ LED 灯带(开关 + 0–100 亮度滑杆)/ 低功耗开关 / 时间(同步状态 + 上次同步时间 + 立即同步、时区读写)/ 账户(用户名只读 + 修改密码双确认 + ⚠ 提示)。
13. **虚拟设备**:虚拟 U 盘(sd / emmc)挂载/卸载、虚拟网卡(RNDIS)、虚拟麦克风(UAC);切换有"键鼠会短暂重连"提示;写后回读校验。
14. **Tailscale**:五态状态卡(未安装 / 未运行 / 未登录 / 已停止 / 运行中)+ 节点名 / IP / 账号;操作:安装 / 启动 / 登录(返回 URL 可复制授权)/ 断开 / 停止 / 重启 / 卸载;固件无此功能时整页降级提示。
15. **系统更新**:当前版本 vs 最新版本对比、"预览通道"开关、二次确认后在线更新(长超时专用客户端)。

### 3.5 Terminal 终端页

- 顶栏 48dp:按入口显示标题(Shell / 串口 / 助手安装)+ 退出按钮。
- WebView 渲染离线 xterm.js 4.19(纯黑沉浸,等宽),底层是设备 `/api/vm/terminal` pty:
  - Shell 入口直接是设备 root shell;
  - 串口入口自动注入 picocom(带 §3.4-8 的参数);
  - 助手安装入口自动执行 `pip install -r /tmp/requirements.txt`。
- 流式解码输出(防多字节字符切裂);断线指数退避重连;WS 返回 401/403 时弹出 SSH Basic 认证对话框(用 token 校验)。
- 点按终端显式弹软键盘;外接物理键盘直接输入。

### 3.6 Assistant 智能助手页(设备端 AI,cua)

- **顶栏**:服务状态文字(未连接 / 执行中 / 等待输入 / 在线)+ 状态圆点 + 刷新(重连)/ 设置 / 退出。
- **实时桌面缩略图**(页面主角):MJPEG 直连设备 5000 端口,看到 AI 正在操作的实时桌面;400ms 节流 + 2s 自动重试;竖屏为顶部条带(高度按屏宽 38% 自适应 240–400dp),**真横屏宽窗(≥600dp 且宽>高)切换左右双栏**(左 45% 画面 / 右消息流),平板竖屏与手机一致上下堆叠。
- **消息流气泡**:任务下发后的 思考 / 动作 / 截图(每轮一张)/ 错误,按时序滚动。
- **输入行**:圆角输入框 + 48dp 发送主按钮;占位文案随任务状态变化(描述任务…/ 等待当前轮结束…)。
- **任务控制**:开始 / 暂停 / 恢复 / 重置。
- **设置对话框**:api_type / api_key / base_url / model_name / 截图保留轮数 / 最大轮数;分组排列、API Key 等宽可换行、保存中状态。
- **会话接管**(纯客户端):设备端助手是单用户 token 服务,被旧会话占用时,刷新页会自动杀旧服务、重启并认领新 token(10s 窗口防双端互踢,全程 12–25s,免重启设备);403"single user"错误即触发场景。

## 4. 全局机制(再设计需保留的心智)

- **主题**:SYSTEM(跟随 OS)/ 浅色 / 深色;切换入口两处(连接页右上、控制台顶栏  /☾);选择持久化;全部界面深浅双套。
- **持久化**(DataStore):host、username、password(明文,局域网 MVP 取舍)、streamMode(默认 h264-direct)、mouseMode(默认 absolute)、theme。
- **重连模型**:连接断开自动指数退避重连,顶栏 chip 显示"重连中 N";设备无信号时停止看门狗靠遮罩,避免重连风暴。
- **工具箱参数即生效**:改码率/帧率/GOP 会重建视频流(顶栏会话 chip 闪断属预期);旋转/缩放仅本端显示。
- **平板/大屏**:助手页真横屏双栏;其余页面内容限宽居中(连接卡 ≤480dp、设置 ≤560dp、工具箱 ≤720dp、键盘 ≤960dp)。

## 5. 技术硬约束(UI 设计不能假设可用的能力)

1. **WebRTC 渲染层不支持视图旋转/缩放**(SurfaceView 限制)——相关控件在 webrtc 模式必须禁用并说明原因。
2. **粘贴/虚拟键盘只能发标准键盘字符**(HID 协议),中文输入只能走终端等间接途径;粘贴 ≤1024 字。
3. **镜像挂载、虚拟设备切换会重启 USB gadget**——键鼠会断连数秒,任何相关交互都要保留警示文案。
4. **改流参数 = 重建视频流**(设备编码器参数仅在初始化时生效)。
5. **破坏性操作必须二次确认**:电源短按/长按、被控机复位、设备重启、重置 HID、删除镜像/EDID/WOL 记录、修改密码、在线更新。
6. **视频流四通道**(h264/h265 × 直连/WebRTC)由设置 Sheet 二轴组合,切换必须重连;UI 不做逐通道独立入口。
7. 统计指标可测性:WebRTC 下编码/采集/解码延迟收端不可测(不显示空瓦片);总测延迟是估算值。
8. 布局红线(Compose 本机坑):Row 中 weight 之后的兄弟不渲染——新布局要么 weight 容器置前,要么不用行内 weight 兄弟。

## 7. 已知体验短板(优化切入参考)

1. **工具箱层级深**:高频动作(终端/助手)埋在 抽屉 → 行 → 弹窗/跳页 三层;可研究把常用项上浮。
2. **长表单弹窗**:"设备设置""显示·时间·账户"单列过长需滚动,分组与锚点弱;失败降级(固件不支持)逐项混排。
3. **统计浮层遮画面**:276dp 卡片压在视频右上角,手机竖屏下遮挡明显;无收起为细条的模式。
4. **顶栏三 chip 在窄屏偏挤**:错误态长文案("重连中 N")可能出现截断。
5. **弹窗加载/错误态各写各的**:15 个弹窗的 busy/error 呈现样式不完全一致,可统一为组件。
6. **连接页只有单设备记忆**:换设备要手动改表单(单设备场景取舍,但表单可更聪明)。
7. **无横屏专用控制台布局**:手机横屏时顶栏+工具条占掉的高度比例更差(平板只在助手页有双栏)。
8. **浅色主题为"可用"级**:视频周边 chrome 未做浅色下的对比度细调(spec 明示深色优先,可作为补强项)。
9. **键盘/粘贴无中文**是协议限制,但输入路径的引导文案可以更清楚(现在仅粘贴框有一行警示)。
